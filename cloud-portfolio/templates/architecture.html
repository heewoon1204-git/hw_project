Architecture

AWS VPC와 Amazon EKS를 기반으로 다중 AZ 환경을 구성하고, Application과 Monitoring 영역을 분리하여 서비스 운영 환경을 구축했습니다. ALB, Route 53, S3, RDS, NAT Gateway, Pod Identity, Prometheus와 Grafana가 서로 연결되어 동작합니다.

AWS Resources

Route 53

ALB
HTTPS Listener, IngressGroup 및 Path 기반 서비스 라우팅
NAT Gateway
Private Subnet의 외부 통신 및 EKS Workload의 outbound 통신 지원
RDS
PostgreSQL 기반 데이터베이스 환경
S3

ECR

IAM / Pod Identity

EKS Add-ons

ALB Log Viewer
