# RDS 구성

## RDS 설치하기

### 1. RDS 설치 전 사전작업

1. DB subnet group 만들기

    RDS → Subnet groups → Create DB subnet group 

    ```bash
    Availability Zones : a, c zone
    Subnets : private-subnet-a, private-subent-c
    ```

2. RDS Security Group 만들기

    ```bash
    Type: PostgreSQL
    Port: 5432
    Source: Application Node Group에서 사용하는 SG
    ```
<br>

### 2. RDS 설치

DB는 PostgreSQL 사용

RDS → Databases → Create database → Full configuration

```bash
Engine type : PostgreSQL
Choose a database creation method : Full configuration
Templates : Dev/Test
Availability and durability : Single-AZ DB instance deployment (1 instance)
Engine version : PostgreSQL 16.14-R2
Master username : postgres
Instance type : db.t4g.micro
Storage type : gp3
Compute resource : Don’t connect to an EC2 compute resource
```
<br>

### 3. 연결 확인

```bash
# EKS에 임시 PostgreSQL Pod 띄우기
kubectl run postgres-client \
  -n application \
  --rm \
  -it \
  --image=postgres:16 \
  -- bash

# rds 접속
psql \
  -h hw-rds-postgres.c9z6hwwrfja3.ap-northeast-2.rds.amazonaws.com \
  -p 5432 \
  -U postgres \
  -d postgres
```
<br>

### 4. RDS에서 사용할 시크릿 생성하기

```bash
# 시크릿 생성
kubectl create secret generic cloud-portfolio-db \
  -n application \
  --from-literal=DB_HOST='hw-rds-postgres.c9z6hwwrfja3.ap-northeast-2.rds.amazonaws.com' \
  --from-literal=DB_PORT='5432' \
  --from-literal=DB_NAME='postgres' \
  --from-literal=DB_USER='postgres' \
  --from-literal=DB_PASSWORD="$DB_PASSWORD"

# 생성 확인
kubectl get secret cloud-portfolio-db -n application
```

<br>

### 5. cloud-portfolio Deployment에 Secret 연결하기

yaml에 secretRef 추가한 뒤 apply 하기 <br>
Deployment에 secret를 추가했기 때문에 해당 pod들은 시크릿을 사용할 수 있게됨

```bash
# Deployment ymal에 추가
envFrom:
  - secretRef:
      name: cloud-portfolio-db
```

### 6. pod에서 시크릿 확인하기

```bash
kubectl exec -n application deploy/cloud-portfolio -- \
  sh -c 'echo $DB_HOST && echo $DB_PORT && echo $DB_NAME && echo $DB_USER'
```

### 7. 접속 확인하기

```bash
# 확인
curl -k https://www.heewoon1204.com/api/db-health

# 결과
{
  "database": "connected"
}
```

## 테이블 구성하기

### 1. PostgreSQL 클라이언트 Pod 실행하기

```bash
kubectl run postgres-client \
  -n application \
  --rm \
  -it \
  --image=postgres:16 \
  -- bash
```

### 2. RDS 접속하기

```bash
psql \
  -h 'hw-rds-postgres.c9z6hwwrfja3.ap-northeast-2.rds.amazonaws.com' \
  -p 5432 \
  -U postgres \
  -d postgres \
  "sslmode=require"
```

### 3. 테이블 생성

```bash
CREATE TABLE incidents (
    id BIGSERIAL PRIMARY KEY,
    incident_type VARCHAR(100) NOT NULL,
    status VARCHAR(30) NOT NULL,
    description TEXT,
    started_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    resolved_at TIMESTAMPTZ,
    root_cause TEXT,
    resolution TEXT
);
```
