# EKS 생성하면서 발생한 문제

## 1. node group 생성 시 서버가 API Server에 등록되지 않는 장애

### 장애 현상

EKS Node group 생성 시 ec2가 만들어져서 aws console에서 확인이 됐지만, kubectl get nodes 하면 node가 보이지 않는 현상.

ec2 서버는 생성됐지만, 쿠버네티스에 등록이 되지 않은 상태 <br>
vpc endpoint는 ecr.api, ecr.dkr이 만들어져 있는 상태

### 장애 원인

NAT가 없는 상태로 private에 생성된 ec2가 AWS API를 사용할 수가 없어서 발생한 문제.

eks 노드가 등록되려면 aws api호출을 해야함. 호출하기 위해서는 NAT나 vpc endpoint가 필요한데, ecr.api, ecr.dkr는 컨테이너 관련 endpoint 였고 실질적으로 ec2와 eks가 통신할 수 있는 endpoint가 없어서 쿠버네티스 node로 등록이 되지 않았음.

```bash
[고객 VPC]                          [AWS 관리 VPC]
  Worker Node  ──────────────────▶  EKS Control Plane
  (EC2 인스턴스)    API 호출 필요       (API Server, etcd 등)
```


### 장애 해결

1. NAT 생성

    NAT를 생성하면 private 환경에서 인터넷 통신이 가능하기 때문에 AWS API 사용 가능함

2. ec2, eks endpoint 생성

    노드가 부팅될 때 EC2 API, EKS API를 호출한다. 이때 사용할 수 있는 ec2, eks endpoint를 설정하면 장애 해결

    ```bash
    # 노드 부팅 순서
    1. EC2 인스턴스 부팅
    2. EC2 API 호출 → 자신의 메타데이터/태그 조회. 실패 시 VPC CNI가 pod 네트워크를 구성하지 못함. 노드 NotReady 상태가됨.
    3. EKS API 호출 → Cluster 정보 조회 + 노드 등록 (kubelet bootstrap). 실패 시 노드 등록을 못함
    4. Kubernetes Node로 등록 완료 ✅

    # endpoint
    1. com.amazonaws.<region>.ec2 : 노드 부팅 시 인스턴스 정보 조회, ENI 관리 (VPC CNI)
    2. com.amazonaws.<region>.eks : kubelet → EKS Control Plane 등록, 클러스터 정보 조회
    ```

## 2. kubectl 명령어 사용 시 에러 발생

### 장애 현상

kubectl 명령어 사용했으나 아래와 같은 장애 발생

```bash
aws: [ERROR]: Error when retrieving token from sso: Token has expired and refresh failed
E0810 21:29:03.910656   12114 memcache.go:265] "Unhandled Error" err="couldn't get current server API group list: Get \"https://89C7A13859793622C6B3CF23384EC3D3.gr7.ap-northeast-2.eks.amazonaws.com/api?timeout=32s\": getting credentials: exec: executable aws failed with exit code 255"
```

### 장애 원인

kubectl이 EKS에 접근할 때 aws cli를 통해 SSO 인증 토큰을 가져오는데, SSO 로그인 세션이 만료되어 aws 인증을 못받고 있어서 발생한 장애

### 장애 해결

sso 다시 로그인 진행
```bash
# sso 재로그인
aws sso login --profile hw-infra
```
