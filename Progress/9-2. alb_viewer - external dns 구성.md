# ALB log를 화면에서 간편하게 보여주기

## ExternalDNS 구성 추가하기

### 기존 환경에 ExternalDNS를 설치하게된 이유

1. application namespace에 ALB가 생성되어있고, ALB log viewer pod는 monitoring namespace에 있는 상태임. 
2. 그 상태에서 화면에서 접속하기 위해 application 쪽 ALB를 사용하기 위해 Ingress group을 추가로 적용했음. 
3. 기존 ALB는 삭제되고 신규 ALB가 생성됨
4. ALB가 새로 생겨 기존 ALB 정보를 가지고 있던 Route53 설정을 변경하지 않으면 화면 접속이 안되는 문제가 발생
5. Ingress 변경 시 자동으로 Route53에 적용해주는 ExternalDNS를 추가하기로 결정

```bash
                     Internet
                         │
                         ▼
              www.heewoon1204.com
                         │
                         ▼
                  Route 53
                         │
                         ▼
              ┌─────────────────┐
              │       ALB       │
              │  group: heewoon1204
              └────────┬────────┘
                       │
             ┌─────────┴─────────┐
             │                   │
          path: /           path: /logs
             │                   │
             ▼                   ▼
       nginx Service       alb-log-viewer
             │                   │
             ▼                   ▼
      application Pod       Flask Pod
                                  │
                                  ▼
                             S3 ALB Logs
```

### ExternalDNS 설치

ExternalDNS는 AWS Route 53 API를 호출하기 때문에 AWS 권한이 필요함. <br>
그래서 이번에도 Role 부터 생성함.

1. ExternalDNS에 부여한 IAM Role 생성하기

    ```bash
    Trusted entity type : AWS service
    Use case : EKS - Pod Identity
    Policy :
    {
         "Version": "2012-10-17",
        "Statement": [
            {
            "Effect": "Allow",
            "Action": [
                "route53:ChangeResourceRecordSets"
            ],
            "Resource": "arn:aws:route53:::hostedzone/*"
            },
            {
            "Effect": "Allow",
            "Action": [
                "route53:ListHostedZones",
                "route53:ListResourceRecordSets"
            ],
            "Resource": "*"
            }
        ]
    }
    ```

    | 권한                         | 용도                     |
    | -------------------------- | ---------------------- |
    | `ListHostedZones`          | 어떤 Hosted Zone이 있는지 확인 |
    | `ListResourceRecordSets`   | 현재 DNS 레코드 확인          |
    | `ChangeResourceRecordSets` | DNS 레코드 생성/수정/삭제       |


2. ExternalDNS용 ServiceAccount 만들기

    ```bash
    # external-dns-serviceaccount.yaml

    apiVersion: v1
    kind: ServiceAccount
    metadata:
    name: external-dns
    namespace: kube-system
    ```

3. EKS Pod Identity Association 만들기

    ```bash
    IAM role : 위에서 만든 role 선택
    Kubernetes namespace : kube-system
    Kubernetes service account : 위에서 만든 ServiceAccount 선택
    ```
