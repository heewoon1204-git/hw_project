# Node Group

## 구조

Application : 서비스 실행에 필요한 리소스

Monitoring : Prometheus / Grafana 같은 모니터링에 필요한 리소스

```bash
                    EKS Cluster
                        │
          ┌─────────────┴─────────────┐
          │                           │
   Application Node Group       Monitoring Node Group
          │                           │
     workload=application       workload=monitoring
          │                     Taint: NoSchedule
          │                           │
    ┌─────┴─────┐               ┌─────┴─────┐
    │           │               │           │
 Private A   Private C        Private A   Private C
  t3.large    t3.large         t3.large    t3.large
```

<br>

### Node group 생성 설정


| 항목                    | Application Node Group | Monitoring Node Group            |
| --------------------- | ---------------------- | -------------------------------- |
| **용도**                | Application 실행         | Prometheus / Grafana 등 모니터링      |
| **Instance Type**     | `t3.large`             | `t3.large`                       |
| **Min**               | 2                      | 2                                |
| **Desired**           | 2                      | 2                                |
| **Max**               | 3                      | 3                                |
| **Subnet**            | Private A + Private C  | Private A + Private C            |
| **AZ**                | ap-northeast-2a / 2c   | ap-northeast-2a / 2c             |
| **Kubernetes Label**  | `workload=application` | `workload=monitoring`            |
| **Taint**             | 없음                     | `workload=monitoring:NoSchedule` |
| **Node Update**       | Max unavailable = 1    | Max unavailable = 1              |
| **Node Auto Repair**  | **Enabled**            | **Enabled**                      |
| **EC2 Key Pair**      | 사용 안 함                 | 사용 안 함                           |
| **SSH Remote Access** | 사용 안 함                 | 사용 안 함                           |
| **Launch Template**   | 사용                     | 사용                               |
| **ASG Warm Pool**     | 사용 안 함                 | 사용 안 함                           |

<br> <br>

### Node group 생성 시 AGS

Node group 생성 시 ASG는 AWS가 자동으로 만들어줌

```bash
EKS Cluster
    │
    └── Node Group
          │
          └── AWS가 자동 생성
                │
                ▼
        Auto Scaling Group (ASG)
                │
          ┌─────┴─────┐
          ▼           ▼
        EC2 Node    EC2 Node
```
