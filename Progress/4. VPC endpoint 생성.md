# VPC Endpint

## VPC Endpint

NAT Gateway 없이 Private Subnet에 EKS Node를 배치할 것이기 때문에 endpoint 구성

```bash
# 현재 subnet 구조
Private Subnet
10.0.2.0/24
10.0.4.0/24

Route Table
└── 10.0.0.0/16 → local

인터넷으로 나가는 경로 없음 ❌
NAT Gateway 미사용 ❌
```

추후 EKS node가 AWS 서비스와 통신할 endoint 생성

```bash
EKS Node
   │
   ├── ECR       ← 컨테이너 이미지
   ├── S3        ← 일부 AWS 기능/이미지 관련 통신
   ├── STS       ← IAM Role 임시 자격증명
   └── CloudWatch 등
```

| VPC Endpoint        | 유형        | 필요도 | 이유                        |
| ------------------- | --------- | --- | ------------------------- |
| **ECR API**         | Interface | ⭐⭐⭐ | ECR 인증/이미지 메타데이터          |
| **ECR DKR**         | Interface | ⭐⭐⭐ | ECR에서 컨테이너 이미지 Pull       |
| **S3**              | Gateway   | ⭐⭐⭐ | ECR 이미지 layer 다운로드 경로     |
| **STS**             | Interface | ⭐⭐  | IAM Role/STS API 호출       |
| **CloudWatch Logs** | Interface | ⭐   | CloudWatch 로그 사용 시        |
| **EC2**             | Interface | ⭐   | 일부 AWS API 호출 필요 시        |
| **SSM**             | Interface | ⭐   | Node를 SSM으로 관리할 경우        |


### Endpoint 생성

```bash
                 EKS VPC
                    │
        ┌───────────┴───────────┐
        │                       │
 Private Subnet A          Private Subnet C
        │                       │
        ├─ ECR API ENI          ├─ ECR API ENI
        ├─ ECR DKR ENI          ├─ ECR DKR ENI
        └─ STS ENI              └─ STS ENI
        │                       │
        └──────────┬────────────┘
                   │
              Private Route Table
                   │
             S3 Gateway Endpoint
                   │
                   ▼
                  S3
```
