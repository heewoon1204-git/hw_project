# Route53 구성하면서 발생한 문제

## 1. 도메인(http)으로 접속 시 접속 불가 장애 발생

### 장애 현상

Route53 Hosted zone에 등록된 도메인에 ALB를 A type으로 record 추가하고 도메인 주소로 접속 시 에러 발생

```bash
DNS_PROBE_FINISHED_NXDOMAIN
```

### 장애 원인

"DNS_PROBE_FINISHED_NXDOMAIN"는 www.heewoon1204.com 이름의 DNS 레코드를 찾지 못해서 발생한 장애

record 등록을 "heewoon1204.com만 해서 www가 붙은 도메인을 찾지 못해서 발생한 것.

### 장애 해결

www 라는 별도의 DNS record를 생성해주면 장애 해결

| 항목               | 값                                  |
| ---------------- | ---------------------------------- |
| Record name      | `www`                              |
| Record type      | `A`                                |
| Alias            | ON                                 |
| Route traffic to | Alias to Application Load Balancer |
| Region           | `ap-northeast-2`                   |
| Load Balancer    | **지금 만든 ALB**                      |


### 2. ALB에 HTTPS Listener 추가 후 도메인 접속했을 때 접속 불가 장애 발생

### 장애 현상 

ALB에 HTTPS Listener 추가 후 도메인 접속했지만 접속 시 에러 발생

```bash
ERR_CONNECTION_TIMED_OUT
```

또한 추가한 ALB의 443 Listener에 에러 메세지가 있었음.

```bash
Listener port unreachable

The security groups for your load balancer don't allow traffic on this listener port. Manage your security groups in Security tab.
```

### 장애 원인

ALB에 HTTPS Listener는 추가했지만 ALB security group에 HTTPS가 뚫려있지 않아서 발생함.

### 장애 해결

ALB security group에 HTTPS(443) inbound를 추가해주면 장애 해결
