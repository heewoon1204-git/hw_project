# VPC, Subnet

## VPC, Subnet 생성

### 구조

NAT Gateway 미사용

```bash
                         Internet
                            │
                            │
                     ┌──────▼──────┐
                     │     IGW     │
                     └──────┬──────┘
                            │
                    ┌───────┴─────────┐
                    │       VPC       │
                    │   10.0.0.0/16   │
                    │                 │
                    │ DNS Resolution, │
                    │ DNS Hostnames   │
                    │      활성화       │
                    └───────┬─────────┘
                            │
              ┌─────────────┴─────────────┐
              │                           │
          AZ: a                       AZ: c
              │                           │
      ┌───────┴───────┐           ┌───────┴───────┐
      │               │           │               │
      ▼               ▼           ▼               ▼
   Public          Private     Public          Private
 10.0.1.0/24      10.0.2.0/24 10.0.3.0/24      10.0.4.0/24
      │               │           │               │
      │               │           │               │
   Public RT      Private RT   Public RT      Private RT
      │               │           │               │
      │               │           │               │
      ▼               │           ▼               │
     IGW              │          IGW              │
                      │                           │
                   local                       local
```


### 1. VPC

 - VPC 생성
 - CIDR 10.0.0.0/16
 - Internet Gateway 연결
 - DNS Resolution 활성화
 - DNS Hostnames 활성화


### 2. Availability Zone

- AZ-a 사용
- AZ-c 사용

### 3. Public Subnet

- Public A
    10.0.1.0/24 <br>
    AZ-a <br>
    Public Route Table 연결 <br>
    0.0.0.0/0 → IGW <br>
    EKS/ALB 관련 Tag 설정 <br>
- Public C
    10.0.3.0/24 <br>
    AZ-c <br>
    Public Route Table 연결 <br>
    0.0.0.0/0 → IGW <br>
    EKS/ALB 관련 Tag 설정 <br>

### 4. Private Subnet

- Private A
    10.0.2.0/24 <br>
    AZ-a<br>
    Private Route Table 연결<br>
    10.0.0.0/16 → local<br>
    EKS 관련 Tag 설정<br>
- Private C
    10.0.4.0/24<br>
    AZ-c<br>
    Private Route Table 연결<br>
    10.0.0.0/16 → local<br>
    EKS 관련 Tag 설정
