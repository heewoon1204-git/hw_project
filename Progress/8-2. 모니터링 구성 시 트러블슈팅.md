# 모니터링 구성하다가 발생한 장애

## 1. helm kube-prometheus-stack으로 모니터링 설치하다가 kube-prometheus-stack-prometheus-node-exporter pending 장애 발생

### 장애 현상

elm kube-prometheus-stack으로 모니터링 설치하는데 프로메테우스, 그라파나 등 다른 pod는 정상적으로 떴는데 kube-prometheus-stack-prometheus-node-exporter만 pending된 상태

```bash
Events:
  Type     Reason            Age                    From               Message
  ----     ------            ----                   ----               -------
  Warning  FailedScheduling  18m                    default-scheduler  0/4 nodes are available: 1 node(s) didn't have free ports for the requested pod ports, 3 node(s) didn't satisfy plugin(s) [NodeAffinity]. no new claims to deallocate, preemption: 0/4 nodes are available: 1 No preemption victims found for incoming pod, 3 Preemption is not helpful for scheduling.
```

### 장애 원인

node-exporter가 3개 세트가 있어서 이미 9100 포트를 사용하고 있기 때문에 port 문제로 pod가 pending 됐던 것

```bash
amazon-cloudwatch
└── node-exporter × 4        ← CloudWatch 쪽

prometheus-node-exporter
└── prometheus-node-exporter × 4  ← 별도로 설치한 것

monitoring
└── kube-prometheus-stack-prometheus-node-exporter × 4  ← 지금 설치한 것
```

### 장애 해결

kube-prometheus-stack 하나로 Prometheus 모니터링을 구성하고 기존 9100 포트 사용하고 있는 prometheus-node-exporter를 제거

1. DaemonSet 삭제

    DaemonSet 삭제하면 pod도 같이 삭제됨
    ```bash
    kubectl delete daemonset prometheus-node-exporter \
    -n prometheus-node-exporter
    ```

2. namespace 삭제

    삭제 전에 사용되고 있는게 있는지 확인

    ```bash
    # 확인
    kubectl get all -n prometheus-node-exporter

    # 결과
    NAME                               TYPE        CLUSTER-IP      EXTERNAL-IP   PORT(S)    AGE
    service/prometheus-node-exporter   ClusterIP   172.20.95.139   <none>        9100/TCP   2d3h
    ```
